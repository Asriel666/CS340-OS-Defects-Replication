## 方法

输入为作者固定版本的 1,500 条标签，各系统 500 条。解析 HTML 数据数组，不执行 JavaScript；校验 SHA-256、数量、系统内 ID 唯一性和分类标签。基准从[论文 Table II](https://arxiv.org/html/2608.20643v1#S4.T2)单独转录，未从计算结果反填。

每类比例为带有该标签的缺陷数 / 500 × 100。系统层次、受影响功能、触发场景和严重性是单标签；代码元素是多标签。6、8、7、5、12 个类别分别乘三个系统，共 114 项。

新增参考表检查拒绝类别缺失、错序、百分比数组长短不符和错误多标签配置，防止 `zip` 静默少比较。CSV 保留论文值、计算值、百分点差、匹配状态及来源。
